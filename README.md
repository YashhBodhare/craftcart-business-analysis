# 🛒 CraftCart – End-to-End Business Analysis Project

## 📖 Project Overview

CraftCart is a comprehensive Business Analysis portfolio project that simulates the development of an e-commerce marketplace for handmade products.

The project demonstrates the complete Business Analysis lifecycle, from requirements gathering through solution design, documentation, process modelling, and User Acceptance Testing (UAT).

---

# 🎯 Business Objectives

- Improve the online shopping experience
- Reduce payment failures
- Improve inventory visibility
- Streamline seller order management
- Increase customer satisfaction
- Demonstrate complete Business Analysis practices
